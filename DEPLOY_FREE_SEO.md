# VidsGrab — Free deployment + SEO setup

## Important limits
This is a free-tier demo deployment, not guaranteed production hosting. Render Free web services sleep after 15 minutes without traffic and have an ephemeral filesystem. Downloaded files may be lost on restart/sleep/redeploy. Long video downloads, FFmpeg conversion, heavy traffic, and extractor/site restrictions can fail on free compute.

## Deploy (Render free)
1. Create a GitHub repository and upload the project files (do not upload `venv` or `downloads`).
2. Sign in to Render and choose **New → Blueprint**; connect the GitHub repo.
3. Render reads `render.yaml`. Confirm the web service plan is **Free** and deploy.
4. After deployment, open the `onrender.com` URL. First visit after idle may take about a minute to wake.
5. In Render service environment, set `SITE_URL` to the exact public URL, without a trailing slash. Redeploy.
6. Test `/healthz`, `/robots.txt`, and `/sitemap.xml`.
7. Submit the site and sitemap in Google Search Console.

## SEO included
- Search-intent title and meta description
- Canonical URL, Open Graph tags and mobile viewport
- Crawlable explanatory text and FAQs
- WebApplication JSON-LD
- `robots.txt` and XML sitemap

## SEO after launch
- Verify the site in Search Console.
- Publish original helpful tutorials and help pages.
- Add genuine contact/support, privacy policy and terms pages.
- Monitor indexing and Core Web Vitals.
- Earn relevant legitimate links. Avoid keyword stuffing, fake traffic, link schemes, and autogenerated doorway pages.

Google ranking or first position for “youtube video downloader” cannot be guaranteed. Google says inclusion and ranking are not guaranteed, even when SEO best practices are followed.

## Usage
Allow only content users own or are authorized to download. Respect source site terms, copyright, and access controls.
